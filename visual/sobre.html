SOBRE A VOINICH

Uma experiência digital para explorar veículos, conhecer modelos e aproximar clientes de uma vitrine automotiva.

Mobilidade, tecnologia e experiência

A Voinich Motors é um projeto acadêmico de desenvolvimento web voltado ao segmento automotivo. A proposta é reunir uma vitrine de carros e motos com páginas de apresentação de veículos e uma área administrativa para gestão de cadastros.

A versão original foi construída com PHP, MySQL, HTML, CSS e JavaScript. Esta publicação na Vercel apresenta uma experiência visual estática, adaptada para navegação e demonstração.
